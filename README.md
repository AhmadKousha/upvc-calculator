# 📊 UPVC Calculator - محاسبه‌گر قیمت لوله‌های UPVC

[![PWA](https://img.shields.io/badge/PWA-Enabled-blue)](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

یک برنامه وب پیشرفته و کاملاً آفلاین برای محاسبه قیمت فروش لوله‌های UPVC با قابلیت نصب روی گوشی‌های اندروید و iOS.

## 🚀 ویژگی‌ها

- ✅ **کاملاً آفلاین** - بعد از بارگذاری اولیه، بدون نیاز به اینترنت کار می‌کند
- ✅ **قابل نصب روی موبایل** - با استفاده از PWA روی صفحه اصلی گوشی نصب می‌شود
- ✅ **محاسبه خودکار** - با وارد کردن قیمت‌های پایه و درصد سود، قیمت‌ها محاسبه می‌شوند
- ✅ **خروجی متن و عکس** - قابلیت کپی متن یا ذخیره عکس از جدول قیمت‌ها
- ✅ **مدیریت محصولات** - امکان اضافه کردن، ویرایش یا حذف محصولات
- ✅ **فیلتر بر اساس کیفیت** - نمایش محصولات با کیفیت قوی، نیمه‌قوی یا معمولی
- ✅ **رابط کاربری زیبا** - طراحی مدرن با پشتیبانی کامل از زبان فارسی

## 🛠️ تکنولوژی‌های استفاده شده

- HTML5 / CSS3
- JavaScript (Vanilla)
- [html2canvas](https://html2canvas.hertzen.com/) - برای خروجی عکس
- [Vazirmatn](https://github.com/rastikerdar/vazirmatn) - فونت فارسی
- Progressive Web App (PWA)
- Service Worker

## 📱 نصب روی موبایل

### اندروید (Android)
1. مرورگر **Chrome** را باز کنید
2. به آدرس برنامه بروید
3. روی منوی سه نقطه (⋮) کلیک کنید
4. گزینه **"Install App"** یا **"Add to Home Screen"** را انتخاب کنید
5. روی **Install** کلیک کنید

### iOS (iPhone/iPad)
1. مرورگر **Safari** را باز کنید
2. به آدرس برنامه بروید
3. روی دکمه **Share** (مربع با فلش بالا) کلیک کنید
4. گزینه **"Add to Home Screen"** را انتخاب کنید
5. روی **Add** کلیک کنید

## 🔧 نحوه استفاده

1. قیمت هر کیلو برای سه کیفیت (قوی، نیمه‌قوی، معمولی) را وارد کنید
2. درصد سود مورد نظر را تعیین کنید
3. روی دکمه **"محاسبه قیمت"** کلیک کنید
4. جدول قیمت‌های فروش نمایش داده می‌شود
5. با استفاده از دکمه‌های **"متن"** یا **"عکس"** می‌توانید خروجی بگیرید
6. از دکمه **"تنظیمات"** برای مدیریت محصولات استفاده کنید
